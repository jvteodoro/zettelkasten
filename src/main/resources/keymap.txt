# Canonical command/keymap reference. Screen-specific keys are described in docs/04-TUI.md.
D    Desk
M    Main
I    Index
B    Bibliography
?    Help
Q    Quit (confirm unsaved draft)

Main:
G    Enter exact address
N    Next physical neighbor
P    Previous physical neighbor

Bibliography:
↑/↓  Select a source
Enter  Read source citation
I    Import a local BibTeX file and review reconciliation
C    Create a user-authored research BibCard for the selected source
B/F  Read the BibCard back/Front
A    Append a located, user-authored BibNote
Ctrl+E  In Main draft editor, enter a literal external reference

Index:
A–Z  Select divider
Enter  Open selected ListIndexCard or read selected pointer
↑/↓  Select overflow card or authored entry
+    Create ListIndexCard after explicitly entering its overflow number
*    Browse dedicated keyterm cards alphabetically
A    Append an authored entry (text, target kind, literal)
P    Promote selected list entry to a dedicated keyterm card; original retained
Esc  Return to divider/keyterm list

Editor:
Ctrl+S  Save draft
Ctrl+L  Insert literal card reference
Ctrl+K  Insert literal Index keyterm reference
Ctrl+E  Insert literal external bibliographic reference
Esc     Cancel dialog / return
Enter   Confirm a literal prompt / insert a newline in the editor
Arrows  Move the editor cursor or select a Desk/Main neighbor
F       File the selected Desk draft at a manually entered address
